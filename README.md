# kong-brain

阿空的個人秘書系統 — 用 GitHub 作為主資料庫，整合日常與工作事務，透過 AI 判斷、執行、審核任務。

## 運作流程

1. **提出需求**：在 `tasks/` 建立一個新任務檔案，描述要做的事。
2. **比對流程**：AI 判斷任務屬於工作或個人，到 `workflow/` 對應分類找有沒有相符的既有流程；有的話套用（可微調），沒有的話新增一份存入 `workflow/`，供之後同類任務使用。
3. **判斷難度、分配模型**：AI 依任務內容評估複雜度，選擇適合的模型處理。
4. **解決任務**：AI 執行任務，產出結果。
5. **AI 自我審核**：檢查產出是否需要修改，必要時反覆修正。
6. **使用者審核**：把結果交給你確認。
7. **審核記錄**：把審核結果、修改建議記錄下來，回到步驟 4 直到你確認完成。

## 資料夾結構

```
kong-brain/
├── README.md          本說明文件
├── docs/              流程規則、決策記錄、任務難度分級標準等說明文件
├── workflow/           可重複使用的處理流程（依任務比對套用）
│   ├── template.md     新增流程時的格式範本
│   ├── work/
│   └── personal/
└── tasks/              實際的任務資料
    ├── work/           工作相關任務
    └── personal/       個人相關任務（除了工作以外的任務都歸在這裡）
```

任務第一層分類只有「工作」與「個人」兩大項：凡是工作相關的放進 `work/`，其餘所有任務一律放進 `personal/`。`workflow/` 與 `tasks/` 採同樣的分類方式，但用途不同——`tasks/` 是實際任務紀錄，`workflow/` 是背後可重複套用的處理方法。
