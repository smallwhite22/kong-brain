# 可用模型與專長紀錄

這份文件記錄目前手邊有哪些 AI 工具、各自能選用什麼模型、各模型的專長，作為「判斷難度、分配模型」這一步的參考依據。模型會不斷更新，建議定期回來核對、更新這份文件（記得在下方版本記錄留下修改日期）。

## Claude（本系統／此雲端環境）

- 目前這個 kong-brain 系統本身就是由 Claude 驅動，負責整體任務判斷、流程比對、審核。
- Claude 目前的模型家族分三個等級：**Opus**（最強、適合複雜推理與長流程任務）、**Sonnet**（本次對話使用的等級，速度與能力平衡，適合大多數日常任務）、**Haiku**（最快最省，適合簡單、明確的任務）。
- 具體版本會持續更新，實際可用版本以 Anthropic 官方文件為準：https://docs.claude.com/en/docs/about-claude/models

## ChatGPT（官方桌面 App，畫面操作串接）

實際打開 App 觀察到的模型選單（2026/9/11 確認）：

| 模型 | 說明 |
| --- | --- |
| Auto | 系統自動依任務挑選合適的底層模型，預設選項 |
| GPT-5.6 Sol | App 內可手動指定的模型版本 |

備註：這個帳號的模型選單目前只看到這兩個選項，沒有看到更完整的模型列表（例如是否有更輕量或更強的版本），之後如果帳號方案有變動，記得回來更新。

## Antigravity（Google 的 AI 開發 IDE）

打開完整模型選單後實際確認（2026/9/11）：

| 模型 | 可調等級 | 專長／說明 |
| --- | --- | --- |
| Gemini 3.6 Flash | Medium（標示 Fast） | 速度快、成本低，適合一般開發任務、快速迭代 |
| Gemini 3.1 Pro | Low / High（可切換思考深度） | 比 Flash 更強的推理能力，適合較複雜的程式或設計判斷 |
| Claude Sonnet 4.6（Thinking） | 內建思考模式 | 平衡型，適合一般複雜度的程式編寫、除錯、文件整理 |
| Claude Opus 4.6（Thinking） | 內建思考模式 | 這個選單裡最強的模型，適合高複雜度、跨檔案整合的任務 |
| GPT-OSS 120B（Medium） | Medium | OpenAI 開源模型，可作為替代選項使用 |

備註：對話輸入框下方目前顯示使用中的模型是「Gemini 3.8 Flash High」，但這個確切名稱沒有出現在上述下拉選單中（選單裡只有 Gemini 3.6 Flash）。研判是版本命名對不齊，或有一個未列在一般選單中的預設/推薦版本，之後使用如果注意到差異，記得回來更新確認。

## 模型分工建議（草案）

依目前掌握的資訊，初步建議：

- **複雜、需要深度推理或跨檔案/跨工具整合的任務**：優先用 Claude（本系統本身）處理，必要時用較高等級（Opus）。
- **一般文字發想、翻譯、簡單問答**：可以交給 ChatGPT App（Auto 或 GPT-5.6 Sol）分擔，減少佔用主系統資源。
- **跟程式碼、IDE 內操作、檔案總管內的專案相關任務**：可以利用 Antigravity，因為它本身就在 IDE 環境裡，能直接操作專案檔案；簡單任務用 Gemini 3.6 Flash 求快，複雜任務可以切到 Claude Opus 4.6 或 Gemini 3.1 Pro（High）。
- 值得注意：Antigravity 裡其實也能選用 Claude 模型（Sonnet 4.6 / Opus 4.6），所以如果本系統之外還想用到 Claude 但走不同的介面，也可以透過 Antigravity 呼叫。

這只是初步分工原則，之後隨著實際使用效果，可以再調整。
